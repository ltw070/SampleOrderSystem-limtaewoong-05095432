# PRD: 반도체 시료 생산주문관리 시스템

> **프로젝트명**: SampleOrderSystem  
> **대상 회사**: S-Semi (가상)  
> **시스템 유형**: 콘솔 기반 관리 시스템

---

## 1. 배경 및 목적

S-Semi는 다양한 반도체 시료(Sample)를 생산하여 연구소, 팹리스 업체, 대학 연구실 등에 납품한다. 주문량 급증으로 엑셀·메모장 기반 관리에서 실수가 잦아지고, 재고·공정 현황 파악이 어려워짐에 따라 체계적인 **반도체 시료 생산주문관리 시스템**을 개발한다.

---

## 2. 이해관계자 및 역할

| 역할 | 설명 |
|------|------|
| 고객 | 필요한 시료를 이메일로 요청 |
| 주문 담당자 | 고객 요청에 맞게 주문서 작성 및 관리 |
| 생산 담당자 | 시료 등록, 주문 수신 후 승인 또는 거절 처리 |

**역할별 흐름**
```
고객 → [시료 요청] → 주문 담당자 → [주문서 전달] → 생산 담당자 → [승인/거절] → 주문 담당자
```

---

## 3. 주문 상태 흐름

```
주문 등록 (RESERVED)
  ├─ [거절] → REJECTED
  └─ [승인]
       ├─ 재고 충분 → CONFIRMED → RELEASE
       └─ 재고 부족 → PRODUCING → CONFIRMED → RELEASE
```

| 상태 | 의미 |
|------|------|
| `RESERVED` | 주문 접수 |
| `REJECTED` | 주문 거절 (모니터링 제외) |
| `PRODUCING` | 승인 완료, 재고 부족으로 생산 중 |
| `CONFIRMED` | 승인 완료, 출고 대기 중 |
| `RELEASE` | 출고 완료 |

---

## 4. 기능 명세

### 4.1 메인 메뉴

전체 시료 요약 정보(등록 시료 수, 총 재고, 전체 주문 수, 생산라인 대기 수)를 표시하고 기능별 메뉴를 제공한다.

| 메뉴 번호 | 기능 |
|-----------|------|
| [1] | 시료 관리 |
| [2] | 시료 주문 |
| [3] | 주문 승인/거절 |
| [4] | 모니터링 |
| [5] | 생산라인 조회 |
| [6] | 출고 처리 |
| [0] | 종료 |

---

### 4.2 시료 관리

| 기능 | 설명 |
|------|------|
| 시료 등록 | 시료 ID, 이름, 평균 생산시간, 수율을 입력하여 등록 |
| 시료 목록 조회 | 등록된 전체 시료와 현재 재고 수량 표시 (페이지 이동 지원) |
| 시료 검색 | 이름 등 속성으로 특정 시료 검색 |

- **수율**: 정상 시료 수 / 총 생산 시료 수 (예: 100개 중 90개 정상 → 0.9)

---

### 4.3 시료 주문

- 주문 담당자가 시료 ID, 고객명, 주문 수량을 입력하여 주문 생성
- 생성 시 주문 상태: `RESERVED`
- 주문번호 형식: `ORD-YYYYMMDD-XXXX`

---

### 4.4 주문 승인/거절

- `RESERVED` 상태 주문 목록 표시
- **승인**: 재고 확인 후 자동 처리
  - 재고 충분 → 즉시 `CONFIRMED`
  - 재고 부족 → 생산 라인 등록 후 `PRODUCING`
- **거절**: 즉시 `REJECTED`로 전환

---

### 4.5 모니터링

**주문량 확인**
- 상태별(`RESERVED` / `CONFIRMED` / `PRODUCING` / `RELEASE`) 주문 건수 표시
- `REJECTED`는 제외

**재고량 확인**
- 시료별 현재 재고 수량 및 상태 표시

| 재고 상태 | 기준 |
|-----------|------|
| 여유 | 주문 대비 재고 충분 |
| 부족 | 주문 대비 재고 수량 부족 |
| 고갈 | 재고 수량 = 0 |

---

### 4.6 생산라인

**생산량 계산식**
- 실 생산량: `ceil(부족분 / (수율 × 0.9))`
- 총 생산 시간: `평균 생산시간 × 실 생산량`
- 생산 완료 시 주문 상태 `PRODUCING` → `CONFIRMED`

**특성**
- 단일 생산 라인 (시료 하나씩 순차 생산)
- 스케줄링 전략: **FIFO (선입선출)**
- 현재 생산 중인 시료 정보 및 대기 큐 목록 표시

---

### 4.7 출고 처리

- `CONFIRMED` 상태 주문 목록 표시
- 선택한 주문을 출고 처리 → 상태 `RELEASE`로 전환
- 출고 수량, 처리 일시 기록
